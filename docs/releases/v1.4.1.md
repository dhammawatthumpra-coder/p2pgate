# p2pgate v1.4.1

Documentation and packaging polish. **No protocol or security behavior changes**
from v1.4.0.

## Changed

- README now shows the one-command install:

  ```sh
  npm install -g p2pgate
  ```

- Added npm version, license, and Node.js badges
- Added a documentation index under `docs/README.md`
- Linked the npm package from the GitHub repository homepage
- Updated install and release documentation to match the published package

## Install

```sh
npm install -g p2pgate@1.4.1
p2pgate --version
```

## Upgrade

```sh
npm install -g p2pgate@latest
```

## Notes

- The `1.4.0` package already contains the functional changes: local control
  plane, `doctor`, trusted-device expiry enforcement, and the interactive
  self-test fixes.
- `1.4.1` updates the npm landing page and documentation only.
