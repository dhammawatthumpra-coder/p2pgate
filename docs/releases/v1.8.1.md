# p2pgate v1.8.1

Documentation-only release. No code, config or protocol change.

## Fixed

The project structure tree in the README stopped at v1.6.0 and skipped several
files. It now matches the repository:

- release notes listed in order: `v1.4.0` → `v1.8.1`
- specs add `phase8-targets.md` (v1.7.0) and `phase9-socks5.md` (v1.8.0)
- `docs/HANDOFF.md` and `docs/SERVICE.md` included
- `scripts/systemd/`, `scripts/termux/service/`, `scripts/windows/` included
- `src/allowlist.js` and `src/socks.js` included

Both `README.md` and `README.th.md` were updated.
