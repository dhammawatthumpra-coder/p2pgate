# p2pgate v1.13.7

Documentation release. No runtime changes.

1.13.6 shipped optional compression but the README did not mention it. This release adds
the missing documentation to the two files npm displays.

## What changed

- `README.md`, `README.th.md`: new section **9.12 Compression (`--compress`)**
  - how to enable it (`--compress` on both ends, or `compress` in config)
  - zstd when available, gzip otherwise
  - works on mux channels and non-mux tunnels, including trusted devices
  - `"compress": "auto"` sampling (mux only) and the 4 GiB / 1000x guard
  - measured 2.4–2.6x on 64 MiB text/log over 4G; ~1.0x for already-compressed files
  - SSH payloads are already encrypted: use `ssh -C` instead
- `config.example.json`: example `compress` block (disabled by default)

## Upgrading

```sh
npm i -g p2pgate@1.13.7
```
