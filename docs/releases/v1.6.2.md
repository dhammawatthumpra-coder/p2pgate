# p2pgate v1.6.2

Wording-only release. No protocol, config, or behaviour change.

## What changed

The client prompt used to say:

```text
🔐 PIN (10 ตัว) หรือรหัสผ่านสำรอง (>=12 ตัว):
```

The phrase "รหัสผ่านสำรอง" (fallback password) is only accurate in the advanced
setup wizard. In the default password mode it *is* the password, so the prompt
made users think they needed a second secret. It now reads:

```text
🔐 PIN (10 ตัว) หรือรหัสผ่าน (12 ตัวขึ้นไป):
```

Related messages were neutralised as well:

| Before | After |
|---|---|
| `PIN ต้องมี 10 ตัวอักษร หรือรหัสผ่านสำรองต้องยาวอย่างน้อย 12 ตัวอักษร` | `ต้องเป็น PIN 10 ตัวอักษร หรือรหัสผ่านอย่างน้อย 12 ตัวอักษร` |
| `รหัสผ่านสำรองต้องยาวอย่างน้อย 12 ตัวอักษร` | `รหัสผ่านต้องยาวอย่างน้อย 12 ตัวอักษร` |
| `ค่า verifier รหัสผ่านสำรองใน config ไม่ถูกต้อง` | `ค่า verifier รหัสผ่านใน config ไม่ถูกต้อง` |

The advanced setup wizard still calls it an "unattended password" because there
it really is a fallback next to the Session PIN.

## Compatibility

- Drop-in replacement for v1.6.1; server and client can be mixed freely.
- No config change, no protocol version change, no dependency change.
