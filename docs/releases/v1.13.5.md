# p2pgate v1.13.5

Repository metadata release. No runtime changes.

The GitHub account was renamed, so the project now lives at:

- **https://github.com/incognitums/p2pgate**

## What changed

| File | Change |
|---|---|
| `package.json` | `author`, `repository.url`, `bugs.url`, `homepage` |
| `README.md`, `README.th.md` | copyright line |
| `docs/HANDOFF.md`, `docs/PRODUCT-HANDOFF.md` | owner and repository/release links |
| `docs/README.md` | `p2phub` link |
| `scripts/systemd/*.service` | `Documentation=` URL |
| `NOTICE` | copyright holder |

Old `github.com/dhammawatthumpra-coder/...` URLs redirect to the new location, but the
metadata on npm is only refreshed by a release — hence this patch.

## Upgrading

```sh
npm i -g p2pgate@1.13.5
```

`npm test` → **82 checks** (unchanged).
