# p2pgate v1.9.1

Documentation-only release.

## Fixed

The README header still said `p2pgate (v1.8)` after v1.9.0 shipped. Both
`README.md` and `README.th.md` now say v1.9 and summarise the 1.9 changes:

- `p2pgate config validate` / `config show`
- doctor: secret fingerprint and age, target reachability, SOCKS policy warnings
- `socks.perClient` per-client allowlists

## Added: documentation guard

`scripts/check-docs.js` (also `npm run docs:check`) verifies:

| Check | Example failure |
|---|---|
| README heading matches `major.minor` | header says v1.8 while package is 1.9.2 |
| both README trees list `v<version>.md` | missing `v1.9.1.md` in the tree |
| `docs/releases/v<version>.md` exists | release notes forgotten |
| `docs/README.md` links that file | index not updated |
| `CHANGELOG.md` has `## [<version>]` | changelog entry forgotten |

It runs inside `npm run check`, which `npm test` and `prepublishOnly` already
chain — so publishing with stale docs fails before the upload.

The `docs/` part is skipped automatically when the script runs from an installed
package (npm does not publish `docs/`).

No code, config or protocol change. `npm test` → 50 checks (unchanged).

## Compatibility

Identical behaviour to v1.9.0; upgrading is only for the corrected documentation.
